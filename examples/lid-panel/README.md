# Synthetic inside-lid panel example

This folder contains one original synthetic schema-v1 lid-panel project in
assembled and exploded FCStd/PNG forms. Its CAD-derived envelope and clearance
exist only inside the synthetic example; they are not dimensions for a
commercial case or evidence of physical fit.

The modular slot grid uses explicit user dimensions rather than assumptions
about any commercial mounting system.
The example is **physical-fit unverified** and must not be treated as a print,
closure, retention, or loaded-carry result.

`lid-panel-controls-unknown-clearance.png` is a clean-profile FreeCAD GUI
capture. It shows the three-tab workflow, the configured slot-grid controls,
the inline Unknown-clearance explanation, and disabled STL/STEP export actions.
