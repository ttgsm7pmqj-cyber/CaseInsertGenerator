# Themed example inserts

This folder contains 23 original examples generated by Case Insert Generator in
FreeCAD. Every example uses a synthetic rounded-rectangle custom-case envelope
and makes no compatibility claim for a commercial case or payload.

Every numbered folder contains:

- an editable assembled `.FCStd` project generated by the add-on;
- a separate `-exploded.FCStd` presentation model whose preview copies are
  spaced apart while its export-enabled result objects remain assembled;
- the schema-version-1 project and evidence record as `.json`; and
- paired native FreeCAD assembled and `-exploded.png` axonometric renders.

[`contact-sheet.png`](contact-sheet.png) shows all 23 assembled examples, and
[`exploded-contact-sheet.png`](exploded-contact-sheet.png) shows all 23 exploded
presentations. [`manifest.json`](manifest.json) records the exact source commit
and source hashes, FreeCAD version, geometry and cold-reopen audits, preview
visibility and placement checks, file hashes, and the overall 23/23 result.

The dimensions are design prompts, not measurements. Every example is marked
**physical fit unverified**, and lid clearance is deliberately **Unknown**, so
space above the case rim is not treated as usable. Food, medical, electrical,
battery, optics, sharp-tool, and load-bearing suitability require separate
material and physical testing.

SVG pockets are omitted from this portable set because the current schema
retains the source path. SVG import is covered by dedicated fixtures and tests;
an SVG should be bundled here only after its asset can be resolved relatively
or embedded in the project.

The generator requires a committed, clean source checkout. It processes all 23
documents sequentially in one FreeCAD process, closes every document after
save/reopen validation, and creates both contact sheets at the end. Exploded
files are presentation aids, not alternate manufacturing layouts; use the
assembled FCStd or export-enabled result objects for STL/STEP output.
