# Security policy

## Supported versions

The `0.1.x` release line receives security fixes.

## Reporting a vulnerability

Please use the repository's private GitHub Security Advisory form. If that form
is unavailable, email `ttgsm7pmqj@privaterelay.appleid.com` with the subject
`Case Insert Generator security report`.

Include the FreeCAD version, operating system, reproduction steps, observed
impact, and—where useful—a minimal synthetic project. Do not attach private,
commercial, confidential, or personally identifying FCStd files to a public
issue. Reports that affect a published release will be fixed in a new patch
release; an existing release tag will not be rewritten.
